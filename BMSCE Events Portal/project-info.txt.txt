PROJECT NAME:
BMSCE Events Portal

PROJECT TYPE:
Web Application

DESCRIPTION:
A centralized web portal for discovering college clubs, events, hackathons and cultural activities at BMSCE.

TECHNOLOGIES:
HTML
CSS
JavaScript
Python
JSON

MY CONTRIBUTION:
Frontend Development
UI Implementation
Event Interface
Search and Sorting Interface
Event Details Interface

PROBLEM:
College event information can be scattered across different club announcements and communication channels, making it difficult for students to keep track of upcoming activities.

The project was designed to provide a centralized platform where students can discover college events and access important event information in one place.

SOLUTION:
The BMSCE Events Portal organizes college activities into different sections such as Clubs, Hackathons and Utsav.

Students can browse clubs, search and sort events, view event cards, open detailed event information and access registration links.

KEY FEATURES:

• Club-based event browsing
• Event cards
• Event details
• Search functionality
• Event sorting
• Registration links
• Hackathon section
• Cultural event section
• Structured event data
• Python-based event data processing
